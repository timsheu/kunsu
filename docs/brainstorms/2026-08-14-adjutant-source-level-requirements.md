# 軍師端防線：斷言層級紀律與副官慣例——需求文件

## Summary

軍師端兩道防線合場定案，全部為帶理由的規範、零新機制：handoff add 指引新增「斷言層級紀律」（凡來源為中介文件的他方系統事實斷言標明來源層級、據以實作級另須一手查證，含「查閱中介文件所得＝二手」定義句）；軍師範本工作流程新增「副官慣例」三件套（用途／負載觸發判準、原文回傳與完備性契約、判斷不外包）、盤點優先序原始碼層與自身狀態斷言查證（另掛 kunsu-inbox 觸發詞）；handoff done 收尾附錨定文本的可觀察訊號自查。混合掛載：紀律在 SKILL 單一副本、慣例在範本、訊號在 done 收尾、自身狀態在 kunsu-inbox 觸發詞；三 live 軍師遷移可與 Invariant #5 計畫合批。

---

## Problem Frame

ebook 軍師研究文件記錄的軍師端失誤有兩個並存成因：**資訊層級不可見**——軍師查 `pages-index.md` 後以「Android 端的事實是」語氣寫進交接，接手方無從分辨是幾手資訊、只能選擇信任，用不嚴謹方法得到正確答案的一方被說服改口；**過載放大錯誤率**——失誤集中於彙整時刻（同讀多份長回覆、跨 3–4 子專案寫下輪交接），連自己 repo 的信箱狀態都憑記憶報錯。

通用 subagent 規範（全域 CLAUDE.md「大範圍研究交 subagent」）已存在卻未生效，成因有兩個並列假說、現有證據無法區分：**判準錯位**——出事場景不像大範圍研究，查一份中介文件核對斷言看起來是「簡單查找」（通用規範反而說直接處理），但做對它是忙碌 context 會偷工的多步深掘；**規則不被查閱**——導致偷工的同一過載機制，可能也抑制「回頭比對規範」這個動作本身（同日剛沉澱的教訓照樣被無視）。前者由觸發判準按用途與負載修正；後者無法靠改寫規範治癒，只能靠可觀察訊號（R10）在實績中判別兩假說何者為主。

「標明來源層級」已有一次正面田野樣本（軍師標注「本節轉引自回覆、未自行查證」後，接手方明確因此把核對升級到原始碼並抓到轉引失真），但混雜前車之鑑因素；且標注的前提是軍師知道自己在哪層——轉引他人回覆有來源意識，查閱中介文件沒有。本設計以字面定義句處理此無意識問題。

## Key Decisions

- **混合掛載**：斷言層級紀律屬交接撰寫行為，進 handoff add 指引——單一副本、本地語境交接同樣受惠；副官慣例與盤點優先序的觸發時刻（規劃前盤點、彙整多份回覆）是軍師專屬流程，進軍師範本工作流程——掛載點須在 session 必經路徑（攔截點教訓）；可觀察訊號自查掛 handoff done 收尾回報（必經路徑第三點，見 R10）。代價是三 live 軍師遷移，可與 Invariant #5 計畫（`docs/plans/2026-08-14-002-feat-invariant5-lifecycle-metadata-plan.md`）的遷移合批執行。
- **「查閱中介文件所得＝二手」寫成字面定義**：無意識問題（軍師主觀認為讀中介文件就構成查核）不能靠自覺解，定義句讓層級判斷變成可比對的規則。Lumen schema drift 規則（實際 schema 為準、migration 僅供參考）為同型先例的一般化。
- **義務拆開分級：措辭義務全涵蓋、查證義務分級**：標明來源層級的措辭（「依 X 記載」）涵蓋所有他方系統事實斷言——措辭成本趨近零、不構成枷鎖，且創始事件的實害通道（事實語氣壓過對方的自查、正確一方被說服改口）不必經據以實作級，唯有全涵蓋才擋得住；一手查證義務才依用途分級（背景說明可停在中介文件；接手方會據以實作的斷言須一手——自查或副官查證），避免查證成本無差別上升。
- **副官是能力提示不是義務**：「可以派」非「必須派」；改變的成本是主 context 的注意力與 context 佔用（落原始碼的深掘外包後趨近零，且新鮮 context 無累積敘事偏見）；token 消耗與等待時間為真實成本，留待計畫期實測（見 Outstanding Questions），不增加逐次負擔。
- **原文回傳與完備性是僅有的兩條硬規則**：副官回傳摘要等於在軍師工作流程內重製中介文件問題（信任副官轉述＝信任 `pages-index.md`）——提取安全、摘要危險；但提取的挑選本身也是判斷、漏挑無矛盾可偵測，故提取副官另須回報掃描範圍與逐份清單，使覆蓋可按份核對而非信任靜默完備。
- **不動 Invariant #2**：層級區分是查證紀律、不是權限變更（唯讀查閱範圍不變），免 ADR 層級流程。

## Requirements

**斷言層級紀律（handoff add 指引）**

- R1. add 指引新增：對他方系統的事實斷言，凡來源為中介文件即標明來源層級（「依 X 記載」措辭），不以「事實是」語氣轉述——措辭義務涵蓋所有他方系統斷言，不分用途。
- R2. 指引含定義句「查閱他方系統的中介文件（規格、索引、對照表）所得＝二手資訊」與查證分級原則：背景說明可停在中介文件（標明層級即可）；接手方會據以實作的斷言（判準：接手方會不會據此寫程式或改設計）須一手——落原始碼／實際狀態查證（自查或副官查證），並於交接內文註明查證方式與位置（`檔案:行號`），留下跨 session 可重建的文本痕跡。
- R3. 指引自帶理由：接手方無從分辨層級只能選擇信任、轉述鏈上任何一環無法定位上游失真、錯誤斷言會使正確答案的一方改口。

**副官慣例（軍師範本工作流程）**

- R4. 工作流程新增副官慣例：主 context 已重、或斷言屬據以實作級時，可派 subagent 以新鮮 context 執行查證；彙整量大時可派提取副官逐份回覆挑原文摘錄（行動項、疑問、矛盾點）。觸發判準按用途與負載、不按規模；為能力提示非義務。done 收尾各查核（沉澱訊號、反向路由）所需的「通讀」仍屬主 context 的讀檔動作，提取副官的摘錄為導讀輔助、不替代該讀檔範圍。
- R5. 原文回傳與完備性契約：副官回傳證據原文＋位置（`檔案:行號`），不回傳改寫過的結論；提取副官另須回報掃描範圍與逐份清單（每份回覆一列、零命中檔案明列「本份無命中」），供主 context 按份核對覆蓋；派遣指示明訂以正體中文回覆。
- R6. 判斷不外包：裁決、規劃、下輪交接與回覆彙整的結論留在主 context，不以「讀多份文件幫我總結」形式外包。

**規劃前盤點（軍師範本工作流程）**

- R7. 規劃前既有盤點優先序補「子專案原始碼」層（現行優先序止於子專案文件）。

**遷移與同步**

- R8. 範本改動同步 ebook／ivm／px 三 live 軍師（可與 Invariant #5 計畫遷移合批）；handoff SKILL 升 minor、kunsu-inbox 依賴聲明同步，kunsu-inbox description 觸發詞增列（R9）併同升版。

**自身狀態斷言（kunsu-inbox 觸發詞＋軍師範本）**

- R9. 對自身 repo 狀態的具體數字或清單斷言（信箱件數、待收尾清單等），報出前以實際指令查證（`ls`、`git status`），不憑對話記憶。掛載採雙點：kunsu-inbox description 增列「信箱幾件」「待收尾有哪些」類口語觸發，使對話回報時刻命中既有掃描腳本而非規範文字（v0.3.0 reply 路由補洞同型修法）；範本句保留為原則陳述。

**可觀察訊號（handoff done 收尾）**

- R10. done 收尾回報附自查，錨定步驟 2 既有通讀的文本、不憑印象回想：對交接本體與回覆中的他方系統事實斷言逐筆點數並回報狀態——據以實作級區分「已一手查證」與「僅標明層級」兩態，後者顯式列為缺口（比照逐項驗收查核的缺口回報慣例，由使用者決定收尾或暫緩）；零筆時顯式回報一行「本輪無他方系統斷言」，使靜默只剩「查核未執行」一種含義。自查計數自文本讀出（R2 的查證痕跡），跨 session 收尾不依賴記憶。僅回報不強制的哲學不變；此訊號作為 Problem Frame 兩假說的判別機制，死信側與生效側皆可觀察。

## Acceptance Examples

- AE1. **Covers R1, R2.** 軍師自 `pages-index.md` 得知某頁 include 狀態並要寫進交接 → 措辭為「依 `pages-index.md` 記載」，或先派副官落 layout XML 查證後以一手語氣陳述並附位置——不再出現「Android 端的事實是」＋中介文件來源的組合。
- AE2. **Covers R4, R5.** 彙整六份長回覆 → 派提取副官逐份回傳原文摘錄＋行號與逐份清單（含零命中明列）→ 軍師以摘錄為導讀先行彙整；done 收尾時反向路由與沉澱訊號查核的通讀仍由主 context 執行，按逐份清單核對覆蓋。
- AE3. **Covers R6.** 副官回傳內容僅含事實與原文摘錄；「彙整結論」「建議裁決」不出現於回傳，下輪交接由主 context 撰寫。
- AE4. **Covers R1.** 本地語境交接（非 kunsu）撰寫者引用他方模組行為 → 同樣適用層級紀律，無語境分支。
- AE5. **Covers R9, R10.** 軍師被問「信箱還有幾件」→ 命中 kunsu-inbox 觸發詞以掃描腳本取得實際件數，不憑記憶作答；本地語境同理，回報待收尾清單前先 `ls docs/todos/` 實際掃描。done 收尾回報末附自查：「本輪 2 筆據以實作級斷言——1 筆已一手查證（副官，附位置）、1 筆僅標明層級，後者列為缺口待裁決」；全輪無他方系統斷言時顯式回報「本輪無他方系統斷言」。

## Scope Boundaries

- 接手方端零改動（矛盾回報 v0.13.0 已完備，三線互補不互相替代）。
- 不強制派副官、不強制逐斷言查證——判準是「可以」不是「必須」。
- Invariant #2 不動；來源層級不新增 frontmatter 欄位（措辭慣例，非結構欄位）。
- 沙盤、kb 工具鏈、SessionStart hook 不動（注意力分裂的結構面已由 hook 兜底）。
