# 交接本體錯誤的勘誤落點與不可變性張力

源自 ebook 軍師 2026-08-13 事件五：已歸檔交接本體被發現有誤（密碼欄位方向寫反），依 Invariant #5 交接本體是定案快照、任何人不得編輯內文（唯一例外 done 收尾的 status 標記），錯誤原封留存 archive/ 成為未來讀者的錯誤參考；回覆信箱是接手方單向管道、軍師不能寫入更正；該工作線無 plan 可記錄。ebook 記錄三個候選方向、均未評估：(a) 允許本體追加「勘誤」區塊（限縮範圍地破壞不可變性）；(b) 建立與 replies/ 對稱的 corrections/ 目錄、由發起方單向寫入（維持單一作者原則，多一個目錄）；(c) 維持現狀、錯誤僅記錄於外部文件（依賴記錄者當下恰好察覺）。與「回覆內容路由」缺口不同類——前者關於輸入、此為已產出輸出的承接機制。涉及 Invariant #5 與單一作者原則，成形後屬 ADR 層級決策，需 /ce-brainstorm 推進。
