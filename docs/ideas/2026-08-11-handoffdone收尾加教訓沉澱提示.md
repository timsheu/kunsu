# handoff done 收尾加教訓沉澱提示

handoff 交接往返裡若出現過翻案、修正、踩坑，最完整的沉澱時點是 done 收尾——done 流程已有逐項驗收查核與來源 todo 查核兩個回頭檢查，對稱加一個「沉澱提示」子步驟（僅提示使用者考慮 /ce-compound、不自動執行，同 kunsu-inbox 收尾提示行模式）。

## 背景 / 動機

出自〈大家都在講 Agent Memory，但「記憶」到底存在哪裡？〉（AILogora）的 Agent Memory 檢驗清單：教訓沉澱目前靠使用者事後想起 /ce-compound，形成時機沒有結構性掛載點；文章典型場景「犯錯被修正→教訓留下」的最可靠觸發點正是收尾時。
