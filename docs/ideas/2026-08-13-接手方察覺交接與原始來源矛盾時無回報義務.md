# 接手方察覺交接與原始來源矛盾時無回報義務

源自 ebook 軍師 2026-08-13 事件五（密碼欄位方向寫反）：軍師交接表格把 register／forgot-password 的密碼欄位數寫反，ios-app 依封包原文實作做對了，但回覆只填自己的實作內容、未標註「與交接所述不符」，軍師靠彙整時比對兩份表格才察覺。現行 reply 協議沒有任何地方要求接手方回報「交接內容與原始來源矛盾」——屬訊號缺席型缺口，2026-08-13 收尾查核計畫的讀方查核讀不到沒寫的東西（該計畫否決寫方標記的理由「寫方訊號不缺」僅對行動項／答案類成立，不涵蓋此類）。風險兩分支都有代價：接手方照交接做→錯誤落地；照原始來源做→軍師錯誤認知存活於定案快照、可跨交接流傳（同事件一形狀）。候選落點：handoff reply 步驟 2「逐項回答附可查核證據」旁補一條「發現交接內容與原始來源矛盾時，即使不影響自身實作也須在回覆中明列」——必經路徑掛載、單一副本、零遷移。
