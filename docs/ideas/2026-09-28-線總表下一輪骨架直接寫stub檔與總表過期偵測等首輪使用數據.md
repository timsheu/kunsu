# 線總表下一輪：骨架直接寫 stub 檔與總表過期偵測，等首輪使用數據

線總表落地後（handoff v0.24.0）兩個延伸方向，來自 code review agent-native 觀察：（1）骨架只印文字不代建檔——若觀察到骨架仍常被忽略（無 series 值的線持續增長、docs/plans 零新總表），下一輪評估產檔腳本直接寫入總表 stub 檔（比照交接本體自動建檔），保留三不變條件中 stdout 單行路徑；（2）總表過期偵測——比照 kunsu-list 的 stale 偵測，總表 mtime 早於最新同線交接 created 時印一行過期提示，屬 advisory 不阻擋。兩者都等第一輪實際使用數據（三 live 軍師是否開始給 series、總表更新頻率）再決定。
